Persistence — Domain Design persistence domain · #4422

Silas (owner) · drafted by Wren · 2026-10-11 · live rows: GET /v1/persistence/… on the model door

Every place Chorus keeps data is one row, and each row says whether it is the original, a copy, something derived, or a cache. A writer collision then shows up in a query, so nobody has to find it by hand.

Where it sits

Borg operating stream
  Read     the hourly crawl (com.chorus.infra-stores-crawl: infra, then stores)
  Surface  findings: an unmapped store; a full disk that a live store sits on

domain  persistence  (owner silas, step proving, graph urn:chorus:domains:persistence)
  └─ PersistenceStore            one class
       parent  onDisk  → Disk     (a dataset or a file store)
            or inStore → its dataset row  (a graph family inside /pods)
       exactly one of the two, enforced by sh:xone

What a row says

fieldmeaning
storeRolesystemOfRecord · copyOf · derivedFrom · cacheOf (exactly one)
roleSourcethe store it copies, derives from or caches. Required unless it is the system of record, and refused when it is.
roleBasismeasured · inventory · inferred: how we know the role. A guess is labelled as one.
writeModelive · closed. A closed archive filling its disk is not a finding.
servedBythe running unit that serves it (a plain link, not the parent)
storeStatuspresent · absent (gone from the machine, kept with its last-seen time) · unmeasured

Where the facts come from

discovered   Fuseki $/datasets, each Domain row's instancesGraph (checked with HEAD),
             files on disk, listening ports joined to ServiceInstance
role         platform/config/store-map.json, authored. A role is a fact about data flow
             and can't be observed, so a store missing from the map is a FINDING, never a guess.

Rules the crawl keeps

changed-only     a second run writes 0
gone ≠ unknown   a store not found → absent; a check that could not run → unmeasured, row untouched
no file writes   no model or seed file may carry a PersistenceStore row (guarded by a bats test)
disk not known   a store whose disk has no row yet is held back and named, not dropped
