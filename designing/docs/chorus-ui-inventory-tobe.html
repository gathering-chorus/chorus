How to review this

Every KEEP/INTEGRATE surface adopts the flow-mock design language via #3761. Every REVIEW surface survives untouched until the integrated journey exists, then gets judged against it — retirement is earned by redundancy proven, not assumed. Corrections to dispositions belong on #3761 as comments; this doc regenerates its verdicts from those.
