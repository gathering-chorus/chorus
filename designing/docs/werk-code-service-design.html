Source of truth. This doc narrates structure and intent. The enforcement mechanisms themselves live in the repo (paths named inline); their pass/fail state lives in pipeline runs and the nightly, never in this file. Where a count appears here it is a snapshot dated 2026-08-15.
Promise. A rule about code that reaches werk-code either fires as a refusal at a named pipeline moment, with a fixture proving it goes red on a violation — or it is listed in this doc as prose, and nobody mistakes it for protection.

The model

Chorus runs two kinds of truth, and the boundary between them is the boundary between athena-model and werk-code. Shape truth — what may exist — belongs to athena-model: SHACL and the DAL refuse a malformed thing at the pen (hand-typed IRIs refused in chorus-model's tbox, placement×derivation checked in adr.rs, instance writes governed at athena-model-gate.sh). State truth — what may transition — belongs to werk-code: the pipeline refuses a forbidden movement of code at the moment it tries to move (commit, test, merge, deploy, accept, nightly).

werk-code is therefore not one program. It is the service contract over every enforcement surface in the pipeline: one vocabulary, one placement rule (a guidance item binds to exactly one moment), and one quality bar (no gate without a negative proof, #3734). The same shape as athena-model — guidance lives as data, violations are refused at the door, and the refusal names its state — applied to code instead of model.

The reason this service exists as a named thing is recorded in its own corpus. Eleven hollow-gate instances in eight weeks (#3734's ledger) taught that a check that cannot go red is worse than no check. And the ADR audit below shows the complementary failure: the three highest-traffic code-discipline ADRs are prose-only, while each one's own text asserts that a convention without a gate is not real (ADR-031: "teeth = the gate"). werk-code is where both failure classes get a single owner.

Vocabulary

TermWhat it is
GuidanceA rule about code: language choice, naming grain, placement, path discipline, test discipline. Authored in an ADR or decision; only real once bound to a moment.
GateA refusal at a moment. Violation → red + typed reason. Examples: werk-commit's rebase-or-refuse (#3186), the accept gate's self-accept refusal (DEC-048).
RatchetA baseline that may only decrease. Per-lint clippy counts (#2532/#3710), per-rule ESLint counts, doc-coherence floor. Climbing = red; new lint unbaselined = red.
Absence guardA gate asserting a retired surface stays dead — the retired-*.bats family, hardcoded-bin-paths baseline. The guard must fail loudly if its target is renamed, never pass vacuously (#3734).
MembraneContext-conditional refusal: test/build contexts refused prod-surface writes (#3615), with the surface list as data (membrane-surfaces.json) and a drift-guard proving enum and schema stay joined.
Negative proofA fixture in which the guarded condition is VIOLATED and the check is shown RED. Ships with the gate or the gate does not land (#3734).
Prose-onlyGuidance with no binding. Legitimate as a stated direction — illegitimate the moment anyone reads it as a backstop. This doc's gap ledger names every one.

Contracts

  • No gate without a negative proof (#3734). The fixture ships in the landing diff. A green run of the fixture is a red flag — the fixture passes only by proving red.
  • A refusal names its state. Typed reasons (no-werk, branch-mismatch, MEMBRANE REFUSED), never a bare exit 1 — the gate-refusal-names-its-state rule generalized from the auth quintet.
  • Ratchets only decrease. A climb is red; an unbaselined new lint is red; regenerating a baseline is legitimate only on a real drop.
  • Unknown is RED (ADR-049). A gate that cannot resolve its input (cdhash unresolvable, store unreachable) refuses; it never passes on absence of evidence.
  • A deleted target fails its guard loudly (#3734). Absence guards and drift-guards (membrane enum_matches_schema) exist so renames can't produce vacuous green.
  • One binding per guidance item. Guidance binding at two moments drifts into two implementations; the earlier moment wins, later moments only verify.

Emitted spine events

  • hook.decision — every edit-time gate verdict, uniform (#3252)
  • membrane.violation — typed, on every refused prod-surface write from a test/build context
  • werk.phase — each pipeline moment's running/pass/fail (#3883), rendered in Jeff's streams (#3884)
  • binary.deployed — the provenance triplet ({binary, cdhash, commit}) that answers "which commit is live?" (#2734)

Not in scope

  • Hosted per-PR CI. Cost-killed 2026-04-29 (#2600); ADR-053 makes the local act run + merge verbs the authority. Does not return without naming why the cost calculus changed.
  • Style enforcement beyond ratchets. Formatting opinions stay in editors; werk-code refuses defect classes, not taste.
  • Path globs for the substrate rule. ADR-038 rejected them explicitly — platform/scripts/ mixes substrate and glue; the graph query is the binding.
  • A workflow engine. Moments chain by spine events (the #2044 direction), not by an orchestrator.
