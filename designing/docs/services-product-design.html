Chorus Tool Runner

One MCP runner that every role, every launchd job and Jeff call into. The runner is written once. Each tool is a row in the model, and athena-gen generates the tool from that row. This is what #4405 did for the heralds, applied to MCP, on the summer MCP release.

Today a tool is hand-written twice and its errors name nothing. After this, a tool is one model row, and every error says who called which tool and why it failed.

Runner core: written once

The core ownsWhat it replaces
Transport: speaks 2026-07-28 (no sessions, method and tool in headers) and still answers 2025 clients.The 400s; the fake session id the hooks client needs
Caller identity: a verified token (the same ES256 check pulse-api uses); unknown callers are refused, never "unknown".The unchecked role header
Dispatch from the generated tool table; per-tool timeout from the row.The 52-case switch and the scattered timeouts
One error line: caller, tool, reason, status, trace. Version probes are counted apart from real faults.Three error paths; alerts that name nothing
One trace id, passed to whatever the tool runs (the traceparent the new spec defines).The orphan trace id
Long-running tools (werk, athena, deploys) use the spec's Tasks extension: start, then check status.15-minute blocking calls

A tool: one model row

Jeff's rule from August stands: a verb is an automated, deterministic Skill. So a tool is a Skill row with a few more fields, not a new class.

FieldExample (herald_run)
name, descriptionherald_run · run one herald against one target
input shape (SHACL → JSON Schema)herald (one of the heralds) · target (a Repository)
ownerprincipal-silas
runsbinary chorus-crawl, or a door collection, or a chorus-api route
timeout, long-running600 s · yes (Tasks)

Model collections need no row at all: athena-gen generates list / get / add tools for every class the door serves (ADR-031 naming). That deletes the hand-written principles, decisions and tree tools.

The cards, in order

  1. Today, tiny: reinstall the SDK so the 1.31 CVE fix is actually in place.
  2. Runner core on the summer release, serving the door collections only. The 400 alerts stop because the cause is gone. It runs beside the old server.
  3. Tool rows on Skill, and athena-gen emits the tool table. First plugin: herald_run (Silas).
  4. Werk and athena verbs move over as plugins, long ones on Tasks.
  5. The old server retires. Its file is deleted, and a check fails if a hand-written tool comes back.
