# chorus share-guard allowlist (#3744)
#
# Path prefixes reachable through the public tunnel, with basic auth, GET/HEAD
# only. Everything not listed here 404s. This file IS the policy — the guard
# refuses to start if it is missing or empty, so the allowlist can never again
# live only inside a running process (2026-07-22 → 2026-08-06, SHARE_ALLOW=/about
# frozen in a hand-started process with no LaunchAgent and no record).
#
# One prefix per line. '#' comments and blank lines ignored.
# Adding a line here EXPANDS what the outside world can reach — review as such.
#
# A line may name the upstream that prefix is served from (#3767):
#     /about   http://localhost:3000
# A bare prefix uses SHARE_UPSTREAM (the plist sets it to :3340). The upstream
# must be loopback — the guard refuses to start otherwise, because pointing a
# public prefix at another host is a reachability change, not a config tweak.
# First match wins, so order matters where prefixes overlap.

# The entrance (#3765) — the top-level Chorus page, served from :3340. "/" means
# the ROOT and only the root: route() treats a bare "/" as an exact match, never
# a prefix. It used to match every path, so this line would have shared the whole
# of :3340 while reading like it shared one page — the guard code narrowing and
# this line land together, and the suite proves /anything-else still refuses.
/

# The about page — the original share (#3644). It lives on the app (:3000), not
# on chorus-api; measured 2026-08-06, :3340 404s it. This explicit route is what
# lets /about and the Athena pages be public at the same time.
/about   http://localhost:3000
