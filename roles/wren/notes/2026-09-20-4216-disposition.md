the live rows: **does the row carry data beyond its own name?** If it does it is an
instance and belongs in a domain graph. If it is a bare name in a closed set it is a
named individual and the schema is its home. The earlier cut — "enumeration vs
instance" — failed because it was a matter of taste; this one is a query.

## Legitimately schema — they stay (7 classes)

**Domain, 41 rows.** Each domain is *punned*: `chorus:properties a owl:Class ,
chorus:Domain`. The row and the class declaration are the same subject, so moving
the row would move the class. This is the one disposition that is not a judgement
call — the schema breaks without it.
