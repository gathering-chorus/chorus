Class Atlas

Live from urn:chorus:ontology + athena-make. Map = dependencies only; each box carries its field and row count, and click a class to filter to its schema. Table = one row per attribute with its definition, whether it is required, its cardinality min..max, what it points at, and the SHACL rule behind it. Reverse (sh:inversePath) rules sort first — those are requirements the class cannot satisfy by its own authoring. Missing definitions are flagged, not hidden.
